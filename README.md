# 📈 Indian Startups Funding Analysis

> A data analysis project developed during a **9-Day Machine Learning Workshop** to explore funding trends in the Indian startup ecosystem using Python and Pandas.

---

## 🚀 Overview

The Indian startup ecosystem has experienced rapid growth over the past decade. This project performs Exploratory Data Analysis (EDA) on startup funding data to uncover valuable insights about investors, funding patterns, startup locations, industries, and investment trends.

The project demonstrates the complete data analysis workflow—from importing raw data to cleaning, preprocessing, analyzing, and visualizing the results.

---

## 🎯 Objectives

- Analyze startup funding data
- Clean and preprocess real-world datasets
- Perform Exploratory Data Analysis (EDA)
- Identify investment trends
- Discover top-funded startups
- Analyze investor activity
- Gain insights using Python

---

## 📊 Dataset

The dataset contains information such as:

- Startup Name
- Industry
- City
- Investment Type
- Funding Amount
- Investors
- Funding Date
